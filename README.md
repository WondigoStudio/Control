# Status Monitor — сайт для мониторинга сайтов и ботов

Простой self-hosted сервис: проверяет доступность твоих сайтов и Telegram-ботов,
хранит историю в SQLite, показывает дашборд и шлёт уведомления в Telegram при падении.

## Возможности

- Проверка HTTP-сайтов (статус-код, время ответа)
- Проверка Telegram-ботов (через метод `getMe`)
- Проверка любого health-эндпоинта (тоже через HTTP-тип)
- История проверок, аптайм % за 24ч и 7д
- Уведомления в Telegram при падении/восстановлении
- Веб-дашборд с карточками и графиком времени ответа

## Установка

```bash
npm install
cp .env.example .env
```

В `.env` при желании укажи `NOTIFY_BOT_TOKEN` и `NOTIFY_CHAT_ID` — это отдельный
Telegram-бот (создать через @BotFather), который будет слать ТЕБЕ уведомления.
Если не указать — уведомления просто будут писаться в консоль сервера.

## Настройка объектов мониторинга

Отредактируй `monitors.json`. Три типа записей:

```jsonc
{
  "id": "уникальный-id",
  "name": "Человекочитаемое имя",
  "type": "http",              // или "telegram_bot"
  "url": "https://...",        // для type: http
  "botToken": "...",           // для type: telegram_bot
  "intervalSec": 60,           // как часто проверять
  "timeoutMs": 8000,
  "expectedStatus": 200        // ожидаемый HTTP-код (для http)
}
```

Для ботов, у которых нет Telegram API (например, свой сервис на сервере),
сделай в самом боте эндпоинт `/health`, возвращающий 200, и мониторь его как `type: "http"`.

## Запуск

```bash
npm start
```

Дашборд будет доступен на `http://localhost:3000`.

## Продакшн / хостинг

Варианты:
- Любой VPS (Timeweb, Selectel, DigitalOcean и т.п.) + `pm2` для автозапуска:
  ```bash
  npm install -g pm2
  pm2 start server.js --name status-monitor
  pm2 save
  ```
- Поставить nginx как обратный прокси на 80/443 с бесплатным SSL через certbot.
- Либо любой Node-хостинг (Render, Railway, Fly.io) — но учти, что бесплатные
  тарифы могут "усыплять" сервис, что сломает регулярность проверок.

## Структура проекта

```
server.js       — Express-сервер + планировщик проверок (node-cron)
checker.js      — логика проверки сайтов и ботов
db.js           — работа с SQLite (better-sqlite3)
notifier.js     — отправка уведомлений в Telegram
monitors.json   — список объектов мониторинга (редактируешь ты)
public/         — фронтенд дашборда (HTML/CSS/JS без фреймворков)
data/monitor.db — база данных (создаётся автоматически)
```

## Как добавить email-уведомления вместо/вместе с Telegram

В `notifier.js` добавь свою логику отправки (например, через `nodemailer`)
и вызови её в `checker.js` рядом с текущим вызовом `notify()`.
